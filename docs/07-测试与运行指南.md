# 07. 测试与运行指南（DP-ORH-MS 智能体）

本文给出从 0 到 1 跑通本仓库 Demo 评测的全流程，覆盖：环境准备、网关配置、API Key 注入、连通性测试、短跑/全量评测、产物校验与常见问题排查。

> **算法**：`DP-ORH-MS`（动态偏好感知的在线滚动时域多目标评分），详见 `docs/06-设计过程思路总文档.md`。
>
> **代码**：决策智能体仅位于 `demo/agent/`；评测沙盒位于 `demo/server/` 与 `demo/simkit/`。

## 1. 环境准备

### 1.1 Python 版本

- **Python ≥ 3.10**（推荐 3.12）。代码使用了 PEP 604（`X | None`）与 `dataclass(slots=True)` 兼容写法。

### 1.2 安装依赖

仓库根目录执行：

```powershell
python -m pip install -r demo/server/requirements.txt
```

依赖很轻：`numpy>=1.26`、`requests>=2.32`。

### 1.3 目录结构（关键文件）


## 2. 配置评测

### 2.1 准备 `config.json`

首次运行需从模板复制：

```powershell
Copy-Item demo\server\config\config.example.json demo\server\config\config.json
```

打开 `demo/server/config/config.json`，把以下三项改成你使用的网关：

```json
{
  "model_api_url": "https://tokenhub.tencentmaas.com/v1/chat/completions",
  "model_api_key": "",
  "model_name": "minimax-m2.5",
  "model_timeout_seconds": 60
}
```

- `model_api_url`：OpenAI 兼容的 Chat Completions 端点。
- `model_api_key`：**保持空**。密钥通过环境变量注入（见 2.2）。
- `model_name`：实际模型 ID（如 `minimax-m2.5`、`qwen3.5-flash`）。

其它字段一般不动：

| 字段 | 含义 |
|---|---|
| `cargo_dataset_path` | 货源数据路径（仅评测沙盒读取，**Agent 严禁直读**） |
| `drivers_path` | 司机数据路径（同上） |
| `reposition_speed_km_per_hour` | 空驶速度（与仿真器一致） |
| `simulation_max_steps` | 全局步数上限 |
| `simulation_duration_days` | 单次仿真天数（本机调试用 1，复赛走 31） |

### 2.2 注入 API Key（**仅当前会话**，不落盘）

`demo/server/bench/settings.py` 优先读取环境变量 `DASHSCOPE_API_KEY` 或 `TIANCHI_MODEL_API_KEY`：

```powershell
# 仅当前 PowerShell 会话有效，关闭后失效（推荐）
$env:DASHSCOPE_API_KEY = 'sk-你的真实key'
```

> **安全提醒**
> - 切勿把含真实密钥的 `config.json` 推到任何远程仓库；`.gitignore` 已排除 `config.local.json` / `*.secret.json` 命名约定的副本。
> - 如果你曾在聊天、截图、邮件中明文分享过 key，请到控制台立即轮换。

## 3. 连通性测试

### 3.1 curl 风格直连

```powershell
$env:DASHSCOPE_API_KEY = 'sk-你的真实key'
curl.exe -X POST 'https://tokenhub.tencentmaas.com/v1/chat/completions' `
  -H "Authorization: Bearer $env:DASHSCOPE_API_KEY" `
  -H 'Content-Type: application/json' `
  -d '{ \"model\": \"minimax-m2.5\", \"messages\": [{\"role\":\"user\",\"content\":\"reply {\\\"ok\\\":true}\"}], \"response_format\": {\"type\":\"json_object\"}, \"stream\": false }'
```

期望返回 `HTTP 200`，`choices[0].message.content` 为合法 JSON 字符串。

### 3.2 Python 一行调用（更稳）

```powershell
$env:DASHSCOPE_API_KEY = 'sk-你的真实key'
python -c "import os, requests, json; r = requests.post('https://tokenhub.tencentmaas.com/v1/chat/completions', headers={'Authorization': 'Bearer ' + os.environ['DASHSCOPE_API_KEY']}, json={'model':'minimax-m2.5','messages':[{'role':'user','content':'reply {\\u0022ok\\u0022:true}'}],'response_format':{'type':'json_object'}}, timeout=30); print(r.status_code, r.json()['choices'][0]['message']['content'])"
```

期望输出：

```text
200 {"ok": true}
```

如果 HTTP ≠ 200，请按 `body` 中的错误码排查（401 Key 错误、404 URL 错误、429 限流）。

## 8. 解读 Agent 日志

### 8.1 偏好解析

```text
偏好解析完成 driver_id=D001 total=4 llm=4 regex=0 failed=0 changes=0
```

- `llm`：成功被 LLM 解析的条目数
- `regex`：LLM 未覆盖、由正则安全网处理的条目数
- `failed`：两道都未覆盖的条目数（会按高风险参与评分）
- `changes`：累计偏好变化事件数（动态偏好检测）

### 8.2 决策摘要

```text
decision driver_id=D001 sim_min=531 items=100 action=take_order score=120.34 note=preferred_cargo token_used=2062
```

- `action`/`score`：最终选择与综合效用分
- `note`：触发的关键软偏好或风险标签
- `token_used`：该司机累计 token 使用量（单司机上限 500 万）

### 8.3 Top 候选明细（DEBUG 级）

把日志级别调到 DEBUG 才能看到 Top 5 候选评分明细。临时调试时可在 `demo/server/bench/evaluation_runner.py` 把 `logging.basicConfig(level=...)` 改为 `logging.DEBUG`。

## 9. 常见问题排查

| 现象 | 可能原因 | 处理 |
|---|---|---|
| `ModuleNotFoundError: numpy` | 未安装依赖 | `python -m pip install -r demo/server/requirements.txt` |
| `未配置模型 API Key` | 未设环境变量也没填 `model_api_key` | `$env:DASHSCOPE_API_KEY='...'` |
| HTTP 401 | Key 错误或过期 | 控制台核对/轮换；确认 `Bearer ` 前缀已加 |
| HTTP 404 | `model_api_url` 路径错 | 检查是否含 `/v1/chat/completions` |
| HTTP 429 | 网关限流 | 降低并发或减少 `--max-steps`；查 `model_timeout_seconds` |
| `LLM 输出不是合法 JSON，降级到正则` | 模型未严格遵守 schema | 已自动回退正则安全网，不影响决策。可换更稳的模型 |
| `cargo_id 已失效` | 选定货源在执行时已被消耗或下架 | 真实风险（文档 14.11），Agent 已有概率折扣机制 |
| `bounded_area_violation` 大量出现 | 偏好限制只能在某市内运行 | 正常硬过滤，可结合空驶把司机带回边界 |
| `token 预算接近上限，偏好解析降级为纯正则` | 单司机累计已超 80% 上限 | 自动降级保安全；可调 `demo/agent/config.py` 中 `TOKEN_DEGRADE_RATIO` |
| 所有步骤都是 `wait` 30 分钟 | 接口异常或全部候选被过滤 | 检查 `note=` 字段；确认偏好解析是否正确 |
