### 2.4 问题四：每日休息不足

**问题描述**：D002违规2次，D006违规2次，D010违规4次，罚款¥1,600

**解决方案**：

```python
# 在build_wait_durations中增强每日休息规划
def build_wait_durations(rules, ctx, memory):
    durations = set()
    
    # 检查每日休息要求
    for rest_rule in rules.rest_rules:
        today_rest = memory.get_today_rest_duration(ctx.current_minutes)
        deficit = rest_rule.required_minutes - today_rest
        
        if deficit > 30:  # 休息不足超过30分钟
            durations.add(deficit)
            durations.add(max(deficit, 180))  # 至少休息3小时
    
    # 夜间时段强制休息
    current_hour = ctx.current_minutes // 60 % 24
    if 23 <= current_hour or current_hour < 6:
        # 休息到早上6点
        wait_to_6am = ((6 - current_hour) % 24) * 60
        durations.add(wait_to_6am)
    
    return durations
```

**预期收益**：减少罚分 ¥1,600

### 3.2 智能空驶优化

```python
# 优化空驶目标点选择
def _build_reposition_candidates(items, rules, ctx):
    targets = []
    
    # 优先级1：家事/熟货目标点
    for event in rules.timed_stay_events:
        phase = timed_event_phase(event, ctx)
        if phase in {"approaching", "pickup"}:
            targets.append((event.pickup_lat, event.pickup_lng, "high"))
    
    # 优先级2：回家点
    if rules.home_rule:
        targets.append((rules.home_rule.lat, rules.home_rule.lng, "medium"))
    
    # 优先级3：热点区域
    if len(items) < 10:
        hotspots = memory.get_top_hotspots(n=3)
        for hotspot in hotspots:
            targets.append((hotspot["lat"], hotspot["lng"], "low"))
    
    return sorted(targets, key=lambda x: {"high": 0, "medium": 1, "low": 2}[x[2]])
```
