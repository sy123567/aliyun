### 6.3 每日休息强制

```python
# 在build_wait_durations中增强每日休息规划
def build_wait_durations(rules, ctx, memory):
    durations = set()
    
    # 检查每日休息要求
    for rest_rule in rules.rest_rules:
        today_rest = memory.get_today_rest_duration(ctx.current_minutes)
        deficit = rest_rule.required_minutes - today_rest
        
        if deficit > 30:  # 休息不足超过30分钟
            durations.add(deficit)
            durations.add(max(deficit, 180))  # 至少休息3小时
    
    return durations
```
